Otto asked for a full project review: architecture assessment, a hunt for
redundant/obsolete structures left behind by design changes made later in
the project's life, and feature-gap-driven new-work recommendations. Three
research passes covered `ARCHITECTURE.md`/`docs/PROTOCOL.md`/`docs/STYLE.md`/
`docs/RELEASE.md`/every `CMakeLists.txt` in full, the entire source tree
(macOS-deferral leakage, TODO/FIXME/legacy markers, orphaned CMake options,
duplicate/`_old`/`.bak` files, stale tests), and all ~268 tasks in
`TODO/done/` (phase timeline, design reversals, per-domain task density,
disclosed out-of-scope items). Findings were published as a report
(Artifact) and walked with Otto, then this task breaks them into real work.

Headline: the codebase is unusually disciplined for its size — `
ARCHITECTURE.md` has caught and corrected its own drift three times, the
wire protocol has only 3 true breaking changes across 32 revisions, and the
source-tree sweep found zero orphaned CMake targets and no dead-code
debris. One review finding ("the WiX custom action is broken, so the
'legacy' PowerShell scripts are the only working path for Windows client
task registration") turned out to be **stale on verification** —
`TASK-00250`/`00252` already fixed this properly via daemon
self-registration on every startup — so no task was filed for it; flagging
here so the correction is on record rather than silently dropped.
