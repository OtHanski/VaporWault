Full-project review (`TASK-00269`) re-surfaced an already-accepted gap
(`docs/RELEASE.md`, `ARCHITECTURE.md`'s "Android release artifact &
signing" decision row): every `.msi`/`.deb`/`.rpm` ships unsigned and the
Android APK is debug-signed (Gradle's standard debug key, not unique to
the project). Worth re-raising now that the release pipeline itself just
proved fragile enough to need a same-day fix (the `v0.5.0` WiX XML-comment
break) — a same class of "nobody verifies the release artifacts are
trustworthy end-to-end until something breaks" risk.

This is explicitly an **investigation** task, not a commitment to
implement signing — a real cert/key has cost and process implications
(who holds it, how CI accesses it securely, renewal) that need a decision
from the project owner, not just an engineering default.

## Acceptance criteria

- Report concrete options and their real cost/complexity for each
  artifact type: Windows `.msi` (Authenticode — cert cost, EV vs. OV,
  SmartScreen reputation implications), Linux `.deb`/`.rpm` (GPG signing —
  much cheaper, self-issued key is viable), Android APK (a real release
  keystore vs. staying debug-signed/sideload-only).
- Explicitly note the CI secret-handling implications (a signing key
  living in GitHub Actions secrets is itself new attack surface — SEC.07
  should weigh in before any implementation, hence the review_by tag).
- Recommend a path (or explicitly recommend staying unsigned with updated
  reasoning) rather than leaving the investigation open-ended.
- No implementation in this task unless the investigation concludes it's
  trivial enough to fold in directly — default to filing a follow-on task.

BLD.05 [2026-09-11]: Investigation complete; decisions made by the
project owner per-platform (this is exactly why this task was filed as

- **Linux `.deb`/`.rpm` (GPG): approved.** No ongoing cost, standard

  is what's actually needed to skip SmartScreen's reputation-building
  period, and EV requires verified business identity this project
  doesn't have). Recorded in `ARCHITECTURE.md` and `docs/RELEASE.md` as a
  permanent decision, not a live gap — matching how this project already
  treats the Windows installer's uninstall-data-retention behavior.
- **Android APK (real release keystore): approved.** Free, no Play Store
  presence needed. Filed `TASK-00289` for implementation.
