The `v0.5.0` release workflow's `Build / Windows / x86_64` job failed at the
"Build installer packages (.msi)" step
(https://github.com/OtHanski/VaporWault/actions/runs/34461935120/job/102821545921).
The Linux job succeeded; the Windows client MSI failed to build (server MSI
built fine).

Root cause, found via the job's dumped `wix.log`:

```
D:\a\VaporWault\VaporWault\packaging\windows\wix\client-extra.wxs(134) :
error CNDL0104 : Not a valid source file; detail: An XML comment cannot
contain '--', and '-' cannot be the last character. Line 134, position 45.
```

`packaging/windows/wix/client-extra.wxs` line 134 (inside the
`UNREGISTERCLIENTTASK` custom-action comment, added for TASK-252) read:

```
hits Unregister-ScheduledTask here -- register-client-task.ps1's
```

The em-dash-style `--` is illegal inside an XML comment body (XML spec
disallows `--` anywhere in a comment, not just at the end) — WiX's
`candle.exe` enforces this strictly and refused to compile the file at all,
so the client MSI (`cpack -G WIX` for the `client` component) never got
produced. This is a plain XML-syntax bug, not a design or protocol issue —
no `docs/PROTOCOL.md` or `ARCHITECTURE.md` change involved.

**Fix applied**: changed the `--` to `;` in that one comment
(`hits Unregister-ScheduledTask here; register-client-task.ps1's`).
Grepped both hand-authored `.wxs` files
(`packaging/windows/wix/client-extra.wxs`,
`packaging/windows/wix/server-extra.wxs`) for any other `--` inside a
comment body — none found (the only other `--` hits in the directory are in
`register-client-task.ps1`'s PowerShell comments and a `--config` CLI flag
in an XML *attribute value* in `server-patch.xml`, neither of which is
inside an XML comment, so neither is affected by this rule). Also validated
both `.wxs` files parse as well-formed XML via PowerShell's `[xml]` parser
post-fix.

Not verified against a real `candle.exe`/`light.exe` run locally (WiX
Toolset isn't installed on this machine) — verification is a real CI run
of the release workflow, per the acceptance criteria below.
