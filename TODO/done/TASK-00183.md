Blocked on `TASK-00182`'s daemon IPC (the GUI consumes the client/daemon API
only, per CLAUDE.md's GUI.03 constraint — no protocol or socket code here).

## Work

- `vw_view_browser.cpp`/`.h`: a "Version history" action on the selected
  file (context menu or toolbar button) opens a panel/dialog listing
  versions via the new `VW_IPC_VERSION_LIST_REQ`, each row showing at
  least version id, timestamp, size, and a "Restore" button.
- Restore requires a confirmation prompt (mirrors the web frontend's
  `window.confirm` behavior — restoring silently overwrites the current
  HEAD, that should not be a one-click accident).
- If the account is on fallback (read-only) or the file is view-only,
  the "Restore" button is disabled with a tooltip explaining why, rather
  than enabled-then-failing.

## Acceptance criteria

- A user can open version history for any file they can see and restore
  an older version through the GUI alone, no CLI needed.
- Restore-not-available states (read-only fallback, view-only permission)
  are visibly disabled, not silently broken buttons.
- Keyboard navigation reaches the new panel (existing accessibility bar
  set by CLAUDE.md's GUI.03 scope).
