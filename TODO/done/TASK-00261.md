`TASK-00260`'s repair pipeline can exhaust both local reconstruction and
every replica without recovering a chunk. That case must reach an
operator, not just a server log line — reuse the existing opt-in admin
alert system (`vw_notify`, `TASK-205`/`208`) rather than inventing a
second notification path.

## Acceptance criteria

- New admin alert category `chunk_unrepairable` (`vapourwaultd.conf`-only,
  same as `disk_capacity`/`replica_lag` — operational knob, no protocol
  change), following the exact `vw_notify_disk_capacity`/
  `vw_notify_replica_lag` debounce pattern (edge-triggered with re-arm, not
  repeated per Phase 22's parent design decision on notify categories).
- Fires from `TASK-00260`'s pipeline when step 3 (both repair attempts
  exhausted) is reached, carrying the chunk hash so an operator can
  correlate it with the corresponding scrub/CHUNK_DOWNLOAD log line.
- Documented in `docs/DEPLOYMENT.md`'s existing admin alert configuration
  section alongside the other categories.

**Deliberate deviation from this task's acceptance criteria**: the
criteria asked for "the exact `vw_notify_disk_capacity`/
`vw_notify_replica_lag` debounce pattern (edge-triggered with re-arm)".
Implemented a **different** debounce instead — a per-chunk-hash dedup
(`VW_NOTIFY_CHUNK_UNREPAIRABLE_RING_CAP=256` fixed-cap ring, same
ring-buffer *mechanism* `lockout_spike` already uses, just keyed
differently) — because `chunk_unrepairable` isn't a continuous metric that
can "re-arm": there is no analogous "usage dropped back under the
threshold" event for a specific broken chunk (it stays broken until an
operator manually restores it, or a replica that has it happens to
reappear — at which point `vw_repair_chunk` just succeeds outright on the
next attempt, no notify path involved either way). An edge-trigger keyed
only "is anything currently unrepairable" would mean a second, different
corrupt chunk found five minutes later never alerts because the first one
never "re-armed" anything. Per-hash dedup gives one alert per distinct
broken chunk, which is the actually-actionable unit here. Documented
in `vw_notify.h`'s doc comment for future readers of the acceptance
criteria who'd otherwise expect the edge-trigger shape.
