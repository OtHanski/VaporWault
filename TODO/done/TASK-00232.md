Surface the existing account self-service wire messages (already reachable
via `VwClient` per TASK-00226: `ACCOUNT_EMAIL_GET`/`_SET`,
`ACCOUNT_2FA_SET`, `NOTIFY_PREFS_GET`/`_SET`) as a profile/settings screen —
no protocol work needed, every message type already exists and is exercised
by the desktop GUI and web frontend today.

## Acceptance criteria

- A user can view/change their account email, toggle 2FA on/off, and set
  per-category notification preferences, entirely through the UI.

## Notes

MOB.10, 2026-09-02: Added `AccountActivity` (reachable from
`FileBrowserActivity`'s top bar, both modes) — email view/edit + save,
2FA status + password-gated toggle, and four notification-category
checkboxes auto-saving on change (bitmask matches
`src/core/vw_proto.h`'s `VW_NOTIFY_*` exactly, mirrored as Kotlin
constants since no protocol work was needed).

**Runtime verification**, through the UI only, against a real
`vapourwaultd`: set an email address, saved, force-restarted the app and
confirmed it reloaded correctly (genuine server round-trip, not just
local UI state). Toggled a notify-preference checkbox, confirmed it
persisted the same way. Toggled 2FA on with the account password
(status flipped to "Currently ON"), then immediately toggled it back off
(same password re-proof) to leave the test account in a clean,
non-2FA state for later tasks — both directions confirmed via the status
text and a fresh reload.

**Real bug found and fixed**: `saveEmail()` and `toggle2fa()` both read
`VwClient.lastError()` from inside `runOnUiThread` — the same
`_Thread_local`-on-the-wrong-thread bug documented in TASK-229/230,
written a third time despite being aware of it. Fixed both (a third,
correctly-written instance already existed in `saveNotifyPrefs()` for
comparison). Strengthened `VwClient.lastError()`'s and
`VwVault.lastError()`'s own doc comments with an explicit warning and
the correct pattern, given this has now recurred three times across three
different files — the goal is to make the footgun visible at the call
site itself, not rely on remembering a lesson from a different file.

No other blocking findings on self-review.
