Reuse existing idioms — no new generic toast framework.

- `ClientApp.cpp`: new `render_update_banner()` sibling to the existing
  `render_offline_banner()` (`ClientApp.cpp:148-159`) — same persistent-top
  banner shape, shown when `VW_IPC_UPDATE_STATUS_RESP.available == 1`:
  "Update available: vX.Y.Z — Update Now / Later". "Later" dismisses for the
  current GUI session only (no persisted snooze state in v1 — banner
  reappears next launch, acceptable since it's non-blocking).
- "Update Now" opens an `ImGui::BeginPopupModal` confirm dialog, mirroring the
  existing daemon-shutdown confirm (`vw_view_settings.cpp:330`) — "this will
  restart the daemon" framing applies almost verbatim, since applying an
  update culminates in exactly that.
- `vw_view_settings.cpp`: new section near the shutdown-confirm block —
  current version display, "check for updates now" button (fires
  `VW_IPC_UPDATE_STATUS_REQ`), "fully automatic" policy toggle (fires
  `VW_IPC_UPDATE_POLICY_SET_REQ`), using the view's existing inline
  "last status message" buffer idiom for feedback.
- **If `install_kind != PORTABLE`**: both the banner and settings section
  render **notification-only** text with a link to the GitHub releases page.
  No "Update Now" button is ever shown, and the GUI never attempts to
  elevate/invoke a package manager itself.
